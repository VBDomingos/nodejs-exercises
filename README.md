# JS Exercises

List of exercises with expected output commented inside each file.

## Prerequisites

Before running the project, make sure you have the following installed on your machine:

    Node.js: This code is written in JavaScript and runs with Node.js.

## Running the Code

Clone the repository:

    git clone https://github.com/your-username/repository-name.git
    cd repository-name

To run the code, open your terminal and navigate to the project directory and navigate to the desired exercise. Then, use the following command to execute the script:
    
    node sum.js
    
Replace sum.js with the name of the JavaScript file depending on the exercise.
